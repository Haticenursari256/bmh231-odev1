## Proje Hakkında
Bu projede Node.js kullanılarak Express olmadan basit bir HTTP sunucusu oluşturulmuştur.

## Kullanılan Teknolojiler
- Node.js
- JavaScript
- Git ve GitHub
- npm
- dayjs

## Kurulum
Projeyi çalıştırmak için terminalde:

```bash
npm install
node sunucu.js
```

Sunucu adresi: http://localhost:3000
