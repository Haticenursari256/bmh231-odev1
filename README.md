## Proje Hakkında
Bu projede Node.js kullanılarak Express olmadan basit bir HTTP sunucusu oluşturulmuştur.

## Kullanılan Teknolojiler
- Node.js
- JavaScript
- Git ve GitHub
- npm
- dayjs

## Kurulum

Projeyi GitHub'dan indirmek ve çalıştırmak için:

```bash
git clone https://github.com/Haticenursari256/bmh231-odev1.git
cd bmh231-odev1
npm install
npm start
```

Sunucu adresi: http://localhost:3000

## Desteklenen Yollar

- `/` — Ana sayfa (HTML)
- `/hakkimda` — Hakkımda sayfası (HTML)
- `/api/ders` — Ders bilgileri (JSON)
- `/api/agep` — AGEP'e kalan gün hesabı (JSON)

Desteklenmeyen adreslerde 404, GET dışındaki HTTP yöntemlerinde 405 yanıtı döndürülür.
